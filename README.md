# Q-Track

Sistema inteligente para la gestión y evaluación de instrumentos quirúrgicos.

## Funciones

- Registro de instrumental quirúrgico.
- Control de desgaste y tiempo de uso.
- Análisis automático del estado.
- Clasificación inteligente.
- Reportes y exportación CSV.

## Tecnologías utilizadas

- Python
- Streamlit
- Pandas

## Ejecutar el proyecto

```bash
streamlit run app.py
```
